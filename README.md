# MedSpatial overview site

The public project page for MedSpatial: https://kkoka1116.github.io/medspatial-site/

MedSpatial is building a shared 3D model of human anatomy that learns from unlabelled CT scans, so tasks such as rib
labelling and pelvic fracture reduction need far fewer expert-labelled cases.

This repository holds only the website: one self-contained `index.html` with its charts and images embedded. It loads
nothing but Google Fonts. The research code, plans and data live in a separate private repository.

- Results are research results on public data, current to 10 November 2026. Not a medical device; no clinical claims.
- Point-cloud renders show one TotalSegmentator v2.0.1 training subject (CC BY 4.0). No sealed test case is shown.
- Dataset credits and licence notes are in the page footer.
